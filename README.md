## 📌 Описание проекта

Веб-приложение для подавления шума на изображениях с использованием фильтров Гаусса и билатерального фильтра. Пользователь загружает изображение, выбирает параметры обработки и получает:

- Обработанное изображение
- Сравнительные гистограммы цветовых каналов (RGB)
- График распределения удалённого шума

## 🧪 Функциональность

- **Загрузка изображений**
- **Выбор фильтра**:
  - Фильтр Гаусса — универсальное сглаживание
  - Билатеральный фильтр — сохраняет края объектов
- **Регулировка интенсивности** сглаживания (от 1 до 10)
- **Наложение временной метки** (дата/время) на изображение
- **Капча** — защита от ботов (арифметический пример)
- **Визуализация**:
  - Исходное и обработанное изображения
  - Сравнительные гистограммы цветовых каналов
  - График распределения шума
